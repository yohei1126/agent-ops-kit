# Work graph (optional module)

This optional module reads GitHub facts to show what is stuck and what to
resolve first. It is not a dependency of the development loop, RETRO, or any
other kit path, and it never writes to GitHub.

Run `scripts/work-graph.sh --help` for what it outputs and how to run it.

The ontology type names (Agent, Process, Artifact, Decision, Block) stay a
draft until the maintainer confirms them.
